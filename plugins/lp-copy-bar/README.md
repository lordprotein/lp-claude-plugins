# lp-copy-bar

Мод Claude Code: строка над полем ввода с кнопками, которые ещё раз копируют сообщения `lp-task` с форматированием. Модель не участвует, кнопка не тратит токены.

```
📋 ACME-123: [MR] [Сообщение для QA]
📋 ACME-124: [MR kit] [MR apps] [Сообщение для QA]
```

- Строка появляется, когда `lp-task` сохранил или скопировал сообщение (`/lp-task:push`, `/lp-task:how-to-test`). По умолчанию lp-task не копирует сам, кнопка и есть способ скопировать. Показываются две последние задачи сессии. Вместе с новым сообщением задачи появляются и кнопки её сообщений, сохранённых раньше (в прошлой сессии или до перезагрузки плагина): мод берёт их из той же папки `messages/`. Если `pushNotes` в конфиге lp-task делят MR задачи на группы, у каждой группы своя кнопка: файл `mr-<группа>` даёт кнопку «MR <группа>».
- Кнопка копирует через `osascript` rich text для Jira и чата (скрипт встроен в мод). Если он не сработал, копирует plain text через терминал.
- `/copy-last` копирует последнее сообщение, в том числе из прошлой сессии.

Мод ничего не знает о проектах: он узнаёт запись файлов и вызов копирования `lp-task` по пути `<stateDir>/<key>/messages/<kind>.html` и берёт сообщение из этих файлов.

## Установка

```
/plugin install lp-copy-bar@lp-tools
```

Нужен macOS для копирования с форматированием; на других системах кнопка копирует plain text.
