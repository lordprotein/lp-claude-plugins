# lp-copy-bar

Мод Claude Code: строка над полем ввода с кнопками, которые ещё раз копируют сообщения `lp-task` с форматированием. Модель не участвует, кнопка не тратит токены.

```
📋 ACME-123: [MR] [Тестерам] [×]
```

- Строка появляется после того, как `lp-task` скопировал сообщение (`/lp-task:push`, `/lp-task:mr-copy`, `/lp-task:how-to-test`). Показываются две последние задачи сессии.
- Кнопка запускает тот же скрипт копирования (`osascript`, rich text для Jira и чата). Если он не сработал, копирует plain text через терминал.
- `×` прячет строку до следующего копирования.
- `/copy-last` копирует последнее сообщение, в том числе из прошлой сессии.

Мод ничего не знает о проектах: он узнаёт вызов копирования `lp-task` по пути `<stateDir>/<key>/messages/<kind>.html` и берёт сообщение из этих файлов.

## Установка

```
/plugin install lp-copy-bar@lp-tools
```

Нужен macOS для копирования с форматированием; на других системах кнопка копирует plain text.
