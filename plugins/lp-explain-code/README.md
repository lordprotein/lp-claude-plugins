# lp-explain-code

Плагин Claude Code, который объясняет код. Не ревью.

| Команда | Что делает |
|---|---|
| `/lp-explain-code:explain [аргумент] [--html]` | Объясняет изменения (пусто, коммит, диапазон, MR/PR, Jira), файл, функцию, компонент или flow «как работает X»; `--html` публикует HTML-страницу |

## Установка

```
/plugin marketplace add lordprotein/lp-claude-plugins
/plugin install lp-explain-code@lp-tools
```
