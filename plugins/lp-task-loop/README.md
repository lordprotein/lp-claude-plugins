# lp-task-loop

Плагин Claude Code: автономный цикл для задачи по коду. Делает, проверяет, ревьюит, ищет изъяны и дорабатывает, пока блокирующих замечаний нет или не кончились итерации. Только правит файлы: не коммитит и не пушит.

| Команда | Что делает |
|---|---|
| `/lp-task-loop:run <задача> [--max N]` | Цикл «реализация → проверка → ревью + скептик → доработка», по умолчанию до 3 итераций |

## Как работает

1. Оркестратор формулирует критерии готовности и находит команды проекта (lint, typecheck, тесты, сборка).
2. `implementer` пишет код. На следующих итерациях это тот же агент: он помнит контекст и получает только замечания.
3. `verifier` (haiku) гоняет lint, typecheck и тесты по изменённым файлам. Если что-то упало, ревью пропускается, и ошибки сразу идут в доработку.
4. `reviewer` (через `lp-code-review:review`, если он установлен) и `skeptic` работают параллельно. Скептик пытается доказать, что задача не решена, и принимается только замечание с доказательством.
5. Если блокирующих замечаний нет, скептик делает финальный полный проход, и цикл завершается. Иначе начинается следующая итерация. Цикл останавливается по лимиту или если замечания не меняются между итерациями.

Для экономии токенов на итерациях ≥2 ревью смотрит только изменения с прошлой итерации, а скептик перепроверяет только упавшие и затронутые критерии. Агенты возвращают компактные таблицы.

## Установка

```
/plugin marketplace add lordprotein/lp-claude-plugins
/plugin install lp-task-loop@lp-tools
/plugin install lp-code-review@lp-tools   # необязательно, для ревью
```
